# 怎样配着源码读

初学者最容易陷入两个极端：只读公式却不知道谁在 backward，或者逐行看代码却失去全局。
我们把阅读拆成三次经过，而不是要求第一遍读完所有分支。

## 第一遍：只追数据与形状

使用 `configs/smoke.yaml`，暂时关闭 MoE、MTP、复杂残差与 RL。
追踪 `input_ids[B,T] → hidden[B,T,D] → logits[B,T,V] → scalar loss`。
在纸上标出哪一项是 token ID，哪一项是概率，哪一项仍需 softmax。

## 第二遍：标梯度与状态

对每个输入写下“训练参数 / 冻结参数 / no_grad 数据 / 持久状态”。
缓存不应被另一条分支原地覆盖；教师分布不应收到学生梯度；old_logp 不应随着更新改变。
`eval()` 只控制 dropout 等模块行为，不等于 `no_grad()`。

## 第三遍：先找反例，再跑训练

| 契约 | 故意破坏 | 应观察到什么 |
|---|---|---|
| 因果性 | 改动未来 token | 过去 logits 不变 |
| cache 等价 | 改变 prefill 切分 | 与完整前向在严格容差内相同 |
| mask | 改变 padding 的数值 | 不改变有效动作的目标 |
| 冻结 | 只反传蒸馏目标 | teacher 无梯度，student 有梯度 |
| held-out | 用答案筛选训练策略 | 这种结果不能再当独立评测 |

## 页面里的代码从哪里来

“源码精读”和“可运行小实验”的代码从对应 Python 符号直接提取。
原始行号保持不变，链接固定到文档构建的 commit；完整源码页可查看导入与上下文。
符号改名但章节未更新时，构建会失败，不能悄悄显示过期代码。

GitHub Markdown 不执行源码嵌入标记，所以直接读仓库时可点击章节中的原文件链接，
或运行实验脚本。在线文档站才显示嵌入后的行号代码。

每章末尾的小结描述应掌握的契约，练习要求一个可区分对错的结果。
章节号与实验号一致，例如 `python scripts/lesson_examples.py 06` 对应 GAE/PPO/GRPO。

## 配置不等于执行

先查 `config.py` 的合法组合，再查 CLI 分派，最后定位 engine/trainer 的调用。
看到一个 YAML 开关不代表它已经接入训练；本书对独立 CSA2、视觉入口、STE 实验有明确标注。
工业阅读项没有假装成可用开关。

## 阅读笔记模板

```text
要解决的问题：
原函数与 commit：
输入/输出 shape：
mask 与 reduction：
参数梯度归属：
状态何时创建、共享、释放：
可证伪测试：
最小实验的观察：
尚不能据此得出的结论：
```

用一个实验填满这张卡，比背下十个新缩写更接近真实研究工作。
