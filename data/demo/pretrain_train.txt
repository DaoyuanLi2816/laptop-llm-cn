语言模型通过观察大量文本，学习根据上文预测下一个词。
训练不是把答案写进程序，而是让神经网络调整许多参数。
参数越多不一定越聪明，数据质量、训练方法和评测同样重要。
一个完整的机器学习实验应当记录配置、随机种子、指标和模型版本。
计算机只能处理数字，因此文字首先要被分词器转换成 token 编号。
字节级 BPE 可以表示任意中文、英文、数字和符号，不会真正遇到生词。
嵌入层把离散的 token 编号变成连续向量。
注意力机制让当前 token 从上文不同位置收集信息。
Query 表示正在寻找什么，Key 表示能提供什么线索，Value 携带实际内容。
因果遮罩保证模型预测未来时不能偷看未来。
RoPE 通过旋转向量注入相对位置信息。
RMSNorm 稳定每一层的数值尺度。
SwiGLU 是带门控的前馈网络，可以学习非线性特征。
残差连接让信息与梯度更容易穿过深层网络。
Grouped Query Attention 让多个查询头共享较少的键和值头。
KV Cache 保存已经算过的键和值，使增量生成不必重复计算整个前缀。
预训练让模型获得语言模式，监督微调让模型学会对话格式。
DPO 使用偏好对，让更好的回答比更差的回答具有更高概率。
训练集用于更新参数，验证集用于观察泛化能力。
测试集应当留到最后，不能反复查看并据此调参。
过拟合是指模型记住训练样本，却不能处理新的输入。
降低学习率、增加数据和使用权重衰减都可能缓解过拟合。
梯度累积用多个小批次模拟一个更大的有效批次。
混合精度减少显存占用，并在现代 GPU 上加快矩阵计算。
梯度检查点少保存中间激活，在反向传播时重新计算，以时间换显存。
困惑度越低通常表示下一个 token 预测越准确，但不等于聊天一定更好。
生成温度为零时选择概率最大的 token，结果稳定但可能重复。
提高温度会增加多样性，也会提高犯错概率。
top-k 只保留概率最高的若干候选。
top-p 保留累计概率达到阈值的最小候选集合。
重复惩罚可以减少模型不断复读同一句话的现象。
模型输出的是每个 token 的 logits，softmax 把它们变成概率。
交叉熵鼓励正确 token 的概率变大。
AdamW 把自适应梯度更新与权重衰减结合起来。
学习率预热能降低训练刚开始时的不稳定。
余弦退火让学习率在训练后期平滑下降。
裁剪梯度可以防止偶发的巨大梯度破坏模型。
断点续训需要同时保存模型、优化器、步数和配置。
可复现并不意味着所有硬件上的浮点结果完全相同。
模型能力受到参数量、有效数据量和计算预算共同限制。
几十万条高质量对话通常比几十条演示对话更有价值。
演示数据的作用是验证代码，不应被宣传为通用智能模型。
中文回答应当先理解问题，再给出清楚、诚实、直接的结论。
不知道答案时，承认不确定比编造细节更可靠。
安全的助手不会声称已经执行实际上没有执行的操作。
好的技术解释会说明输入、输出、关键假设和失败边界。
程序出现错误时，应先保存完整报错，再定位最小复现。
单元测试检查局部契约，端到端测试检查完整流水线。
模型训练完成后，还要验证加载、生成和服务接口。
流式服务会在每个新 token 生成后尽快发送增量文本。
OpenAI 兼容接口让已有客户端更容易连接本地模型。
本地服务默认只监听回环地址，可以减少无意暴露的风险。
如果服务开放到局域网或公网，应设置认证、限流和反向代理。
模型 checkpoint 使用 pickle 容器时，只应加载可信来源。
数据许可证和隐私边界必须在训练前确认。
不要把密码、访问令牌或私人聊天直接放进训练语料。
训练日志应记录损失、学习率、梯度范数和验证指标。
一次负面实验也有价值，它能排除无效的超参数方向。
比较两个模型时，应使用相同数据、提示词、解码参数和评测脚本。
生成质量不能只靠主观挑选几个最好看的例子来判断。
准确性、帮助性、安全性和速度是不同的评测维度。
量化可以降低推理内存，但可能带来精度或速度权衡。
小模型适合学习原理、验证想法和完成窄领域任务。
大模型的骨架与小模型相似，但数据工程和分布式系统复杂得多。

写代码前先明确需求与边界，写完后再运行测试验证。
清晰的变量名和简短注释比重复描述每一行代码更有帮助。

模型不会像数据库一样保证逐字记住所有事实。
检索增强可以在回答前提供外部资料，但仍需检查资料质量。
工具调用把语言模型的计划连接到真实程序，必须验证执行结果。
今天的训练输出不应自动被当作明天仍然有效的事实。
诚实报告模型的限制，是一个完整工程项目的重要组成部分。
